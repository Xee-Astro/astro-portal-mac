# Changelog

## 1.1

- Named public version 1.1 with matching launcher/bundle/installer identifiers.
- Graphical Cocoa launcher with the user-provided Astro Portal icon.
- Persistent manual observing coordinates and Mac location-source selection.
- Mac clock/timezone forwarding and minute refresh during active sessions.
- Fullscreen/windowed DWARFLAB display and saved display preference.
- Vendor APK update button using Android's normal data-preserving update.
- Existing-profile launcher upgrade command, diagnostic logs and public documentation.
- Added source/package checks and documented native/hardware validation limits.

Earlier development packages used the names Astro-DWARFLAB-Mac-Test and versions 0.1.0/0.2.0. Existing internal storage names remain for compatibility.
